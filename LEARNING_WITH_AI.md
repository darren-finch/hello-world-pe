# Learning New Technology with AI

A guide to effectively using AI as a learning tool — not a crutch — when picking up new technologies or patterns for a project.

---

## Core Principles

### 1. Start with a Clear Goal

Define your project with explicit acceptance criteria and a deadline. A time constraint prevents scope creep and analysis paralysis. You can always iterate later — the goal is to get something working first.

### 2. Use AI in Ask Mode

Ask questions freely, but do the work yourself. Try to solve problems independently before turning to AI. When you need an example, study it carefully and then implement it from memory. Use AI to get unstuck or validate your work — not to generate it for you.

### 3. Learn Technologies in Context

Technologies are best understood when used together in a real project. Learning Docker, GitHub Actions, Terraform, K3s, and Redis in isolation is far less effective than integrating them all in a single project. Connections between tools are where real understanding forms.

### 4. Summarize Your Learnings

Write up what you learned in your own words (e.g., in a README). Articulating knowledge solidifies it and makes it easier to communicate to others.

---

## How This Project Was Approached

- **Goal:** Build a simple web app to learn DevOps tooling (Docker, GitHub Actions, Terraform, K3s, Redis) — with something concrete to show employers.
- **Planning:** Used AI to help define the project idea, acceptance criteria, and phase breakdown. Tasks were tracked in Notion to maintain momentum.
- **Deadline:** Started without one, then set a one-month window (which turned out to be more than enough).
- **During development:** Used AI in ask mode for unfamiliar topics; agent mode for tasks already understood. Studied examples deeply before implementing.
- **Wrap-up:** Wrote the README personally to articulate and reinforce what was learned.

---

## Outcome

Came away comfortable with all the technologies used, a solid understanding of how they work together, and a portfolio project that demonstrates real skills.
